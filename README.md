# tab-title-organizer

A browser extension that groups tabs by domain and displays a compact, sorted title list in the action popup.

## Stack

Primary language: **JavaScript**

## Project structure

- `background.js` — Collects open tab titles and domains to provide a quick, organized overview in the popup.
- `manifest.json` — extension manifest
- `popup.html` — popup UI

## Usage

Review the source files and install any dependencies referenced by the project before running it.
